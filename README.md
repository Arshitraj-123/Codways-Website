# Codways website (React + Vite + Tailwind + Framer Motion)

1. Add assets (see public/assets/README.txt) -- logo must be the original file.
2. npm install
3. npm run dev     (npm run build for production)

Routes: / , /products , /products/:slug , /case-studies , /about , /resources , /contact
For hosting, configure an SPA fallback (all routes -> index.html).
Content lives in src/data/content.js (copied verbatim from the original page).
